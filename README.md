# DogePack Classic Beta Install Guide for 1.20 and Newer

You can download **DogePack Classic Beta** from [Modrinth](https://modrinth.com/resourcepack/classic-reimagined-10s), [CurseForge](https://www.curseforge.com/minecraft/texture-packs/classic-reimagined), and this GitHub repository.  

Installation is simple:  
- 📦 Download both the **resource pack** and the [dependency pack](https://modrinth.com/project/ULU4JTr0).  
- ⚙️ If you're using **OptiFine**, make sure you’ve downloaded the mod [here](https://optifine.net) and updated it to the latest version to unlock all features of DogePack Classic Beta.
